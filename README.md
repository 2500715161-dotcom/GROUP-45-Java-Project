# Library Management System

A simple Java-based library management application built to demonstrate core Java concepts such as conditional logic, loops, and menu-driven interaction.

## Features

- View all books in the library catalog
- Search books by title or author
- Borrow a book
- Return a book
- Exit the program

## Project Structure

- `src/Main.java` - Program entry point and menu system
- `src/Library.java` - Core library logic and book management
- `src/Book.java` - Book model

## Run the program

If Java is installed and available on PATH:

```bash
javac src/*.java -d out
java -cp out Main
```

On Windows, you can also run:

```bat
compile.bat
run.bat
```
